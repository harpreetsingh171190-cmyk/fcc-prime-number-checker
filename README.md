
# Prime Number Checker Module

This repository contains the solution for the **Build a Prime Number Checker Module** project, completed as part of the freeCodeCamp Back-End Development and APIs Certification[span_1](start_span)[span_1](end_span).

## Project Overview
The objective of this project is to build a custom prime number checker packaged as an NPM module[span_2](start_span)[span_2](end_span) that passes all required tests and user stories.

## Features
* Validates whether a given number is prime.
* Packaged as a reusable Node.js / NPM module[span_3](start_span)[span_3](end_span).

## Technologies Used
* Node.js
* JavaScript
* NPM

## Setup and Usage
1. Clone this repository to your local machine or Codespaces.
2. Run `npm install` to install dependencies.
3. Run the test suite to verify functionality.
